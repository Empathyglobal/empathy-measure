# Source provenance

This is a sanitized community snapshot of The Empathy Measure, created by Eric Gonzalez-Payne / Empathy Global and prepared for release with the project owner's authorization. The MIT copyright holder is Eric Gonzalez; professional attribution remains Eric Gonzalez-Payne.

The original application includes a handwritten prompt/scoring module (`src/components/cookie/cookie.js`), Base44 application scaffolding, and third-party UI and package dependencies. The core scoring design is retained as experimental source, not endorsed as a validated instrument. The community module omits operational helpers and irrelevant report fields.

The release excludes production configuration, credentials, assessment databases and exports, provider secrets, deployment artifacts, and the original deployment's operational history. A clean public history is used to keep that production context separate; it is not a claim that the application began with the community release.

Community adaptations add safe preview defaults, exclude messaging, server record storage, and operational administration, document data flow and limitations, remove unused dependencies and remote font/image dependencies, and add tests and license notices. No production service is changed by these source modifications.

Sample reports in source are fictional examples, as labeled by the application. Research references are citations and short summaries, not licensed questionnaire item banks. Third-party copyright and dependency licenses remain in force under their own terms.
